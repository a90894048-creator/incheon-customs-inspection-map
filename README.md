# 인천항 세관검사 창고 지도

인천세관 **수입통관 1과 · 2과**의 세관검사 창고 검사 구역(A~H)과 순서를 지도에서 확인하는 한 장짜리 웹페이지입니다.

👉 **https://a90894048-creator.github.io/incheon-customs-inspection-map/**

## 기능

- 구역별 색상 핀에 검사 순서 번호 표시, 같은 구역끼리 점선·화살표로 순서 연결
- 창고명 / 주소 검색 → `수입1과 · G구역 2번째` 형태로 위치 즉시 확인
- 과 · 구역별 필터, 일반지도 / 위성지도 전환
- 여러 창고를 선택하면 검사 순서대로 정렬된 **오늘 동선** 생성
- 카카오맵 · 네이버지도 · 구글지도 길찾기 바로 연결, 주소 복사
- 휴대폰 화면 대응, 다크모드 자동 적용

## 데이터

- 기준: 2026-11-09판 「인천항 세관검사 창고 순서」
- 창고 43곳 (수입1과 20곳 / 수입2과 23곳)
- 좌표는 도로명주소를 지오코딩해 넣었으며, 파일 안 `const DATA = [...]` 배열에 들어 있습니다.

## 수정 방법

창고 순서나 주소가 바뀌면 `index.html` 아래쪽 `const DATA = [...]` 배열에서
해당 항목의 `zone`(구역) · `order`(순번) · `addr`(주소) · `lat`/`lon`(좌표)을 고치고,
상단 `const REV = "..."` 의 기준일자를 함께 갱신하면 됩니다.

## 구성

외부 라이브러리는 지도 렌더링용 [Leaflet](https://leafletjs.com/) 1.9.4 하나뿐이고,
스타일은 파일 안에 포함되어 있습니다. 빌드 과정 없이 `index.html` 하나로 동작합니다.
지도 배경 타일(OpenStreetMap / Esri)을 받아오기 위해 인터넷 연결이 필요합니다.
